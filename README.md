# Phishing Email Detection Using Machine Learning

## 📌 Project Overview

This project detects whether an email is **Phishing** or **Safe** using Machine Learning.

The system uses **TF-IDF**, URL and suspicious-keyword features, and a **Logistic Regression** model to classify emails.

## 🛠️ Technologies Used

## 🔄 Working Process

Email Input  
↓  
Text Cleaning  
↓  
TF-IDF Feature Extraction  
↓  
URL & Suspicious Keyword Features  
↓  
Logistic Regression Model  
↓  
Prediction  
↓  
SAFE / PHISHING

## 📊 Dataset

- Total emails: 82,485
- Phishing emails: 42,891
- Safe emails: 39,595
- Model accuracy: 98.58%

## 🌐 Web Application

The project includes a Flask web application where users can enter an email and receive:

- Phishing or Safe prediction
- Confidence percentage
- URLs found in the email
- Suspicious keywords
- Prediction history
- Confusion matrix
- Dataset statistics

## 🤖 Machine Learning Model

The project uses **Logistic Regression** for classification.

TF-IDF is used to convert email text into numerical features. Additional features such as URL count and suspicious keyword count are also used.
